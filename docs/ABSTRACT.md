# VELTRIX — Project Abstract

## Abstract

VELTRIX is a web-based rehabilitation management platform designed to connect patients and therapists through a centralized digital system.

The platform enables therapists to manage rehabilitation exercises, assign exercises to patients, and monitor patient exercise activity and progress. Patients can access their assigned exercises and complete structured rehabilitation sessions through Guided Mode, where they are provided with exercise demonstrations, instructions, repetition and set tracking, exercise and rest timers, and session guidance.

During rehabilitation sessions, patients can record their pain levels before and after exercise and provide difficulty ratings. This information is stored as part of their exercise session history, allowing patients to track their progress and giving therapists greater visibility into patient activity and rehabilitation outcomes.

VELTRIX also includes Camera Mode Beta as an optional advanced feature for selected exercises. This mode uses computer-vision pose estimation to provide basic real-time movement feedback and repetition tracking where supported. Camera Mode Beta is treated as an enhancement and is not required for the core rehabilitation workflow.

The system is planned as a full-stack web application using React for the frontend, Node.js and Express for the backend, MongoDB for data storage, and REST APIs for communication between the frontend and backend. Authentication uses JWT-based authentication with password hashing and role-based access control.

The primary goal of VELTRIX is to provide a structured, accessible, and centralized rehabilitation experience that helps patients follow their exercise programs while giving therapists useful information for monitoring and managing rehabilitation activities.
